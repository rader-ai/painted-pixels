# What's in the kit

The scene is `SW` x `SH` grid pixels, on a canvas of `DW` x `DH`, with `HD` canvas pixels to a grid pixel. A guide may name something that isn't here. That's one world's own code from Lofi Studio, which you can read as an example at https://github.com/rader-ai/lofi-studio/blob/main/index.html.
